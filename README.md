# Sourcey: Open-Source Documentation Engine

[Sourcey](https://github.com/sourcey/sourcey) is an open-source documentation generator that produces precision static HTML from OpenAPI specs, MCP servers, Doxygen, godoc, and Markdown guides.

## Why Sourcey?

- **Multi-source**: Generates docs from OpenAPI, MCP, Doxygen, godoc, and Markdown
- **Static HTML you own**: Self-hosted, no vendor lock-in
- **Precision**: Docs generated directly from source code and specs
- **Free and open-source**: Self-host on your own infrastructure

## Use Cases

1. **API Documentation**: Generate docs directly from OpenAPI specs
2. **Code Documentation**: Doxygen and godoc support for C++/Go/Java projects
3. **MCP Server Docs**: Documentation for Model Context Protocol servers
4. **Developer Guides**: Markdown-based guides with rich formatting

# Clone the repo
